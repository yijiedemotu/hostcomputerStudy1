## 3. 每周详细任务

### 第 1 周：环境与 C# 基础

- [ ] 装 .NET 8 SDK、VS/VS Code、Git
- [ ] `dotnet new winforms` 跑通 Hello World
- [ ] 学：类型、字符串、数组、循环、方法、调试
- [ ] 写控制台工具：HEX 转换、CRC16、进制转换
- [ ] 验收：能设置断点、单步、看变量

### 第 2 周：C# 进阶

- [ ] 类/属性/继承/接口/泛型/集合/LINQ
- [ ] 异常处理、`using`、`IDisposable`
- [ ] 委托与事件、`async/await`
- [ ] 把上周工具改成“类 + 接口 + 配置”结构
- [ ] 验收：能解释 `IModbusMaster` 为什么这样设计

### 第 3 周：WinForms 界面

- [ ] 控件、Dock/Anchor、布局容器
- [ ] 事件、`DataGridView`、`BindingList`
- [ ] 跨线程 `Invoke`/`BeginInvoke`
- [ ] 搭出串口助手界面（先不接串口）
- [ ] 验收：窗口缩放不变形、按钮有响应

### 第 4 周：串口通信

- [ ] RS232/485 电气知识、接线、终端电阻
- [ ] 串口参数、打开/关闭、异常处理
- [ ] 后台接收 + UI 更新、HEX 解析

- [ ] 验收：用 USB 转 485 或虚拟串口收发成功

### 第 5 周：网络与自定义协议

- [ ] TCP/UDP、三次握手、粘包半包

## 6. 学习技巧

1. **费曼法**：学完一章，假装给同事讲 5 分钟，讲不清就是没懂。
2. **错题本**：每个 bug 记“现象/原因/解决/如何避免”，面试素材。
3. **代码每天一练**：LeetCode 简单题或手写 CRC/排序，保持手感。
4. **读源码**：本仓库代码不多，逐行读 `PollingService` 和 `ModbusTcpMaster`。
5. **番茄钟**：25 分钟专注 + 5 分钟休息，避免“假努力”。
6. **输出倒逼输入**：写博客/笔记，哪怕只有自己看。

## 7. 常见拖延与对策

| 症状 | 原因 | 对策 |
|---|---|---|
| 天天装环境 | 逃避写代码 | 环境 1 小时内搞定，跑通 Hello 就停 |
| 视频看了一堆 | 被动学习 | 看 20 分钟必须敲一遍 |
| 项目越做越大 | 完美主义 | 先做最小可用版，再加功能 |
| 卡在一个 bug | 不会调试 | 记下来，先跳过，第二天再看 |
| 学了就忘 | 没有输出 | 每周写一篇总结/画一张图 |
| 不敢投简历 | 觉得没准备好 | 先投 5 家练手，面试也是学习 |
