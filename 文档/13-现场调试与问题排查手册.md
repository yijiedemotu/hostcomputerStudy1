# 13 现场调试与问题排查手册

> 本章目标：给你一套“到现场不慌”的流程和速查表。
> 这是上位机工程师最值钱的能力——**别人调不通你能调通**。

---

## 1. 上线前检查表

### 1.1 硬件与网络

- [ ] 工控机电源、接地、UPS
- [ ] 网线/串线标签正确，水晶头压好
- [ ] IP 地址不与现场冲突，子网掩码/网关正确
- [ ] 交换机端口、VLAN、防火墙
- [ ] 485 总线 A/B 不反、终端电阻、屏蔽接地
- [ ] 设备上电、指示灯正常
- [ ] 串口驱动已装（设备管理器无黄色感叹号）

### 1.2 软件

- [ ] 安装包版本正确
- [ ] 配置文件 IP/站号/点位与现场一致
- [ ] 数据库路径可写、磁盘空间足够
- [ ] 系统时间正确（时区、NTP）
- [ ] 屏幕分辨率/缩放正常
- [ ] 开机自启、断线重连、异常兜底已验证

### 1.3 联调

- [ ] 单台设备能读
- [ ] 多台设备同时读不冲突
- [ ] 写值能生效并读回
- [ ] 断网/断电恢复后能自动重连
- [ ] 报警能触发、能确认、能恢复
- [ ] 历史数据能落盘、能查询

## 2. 通信故障排查树

```
连不上/读不到
├─ 物理层
│  ├─ 串口：设备管理器有口吗？换 USB 口？换线？
│  │   └─ 485：量 A-B 电压（2~5V）？A/B 是否反？终端电阻？
│  └─ 网口：ping 通吗？Test-NetConnection -Port 502 通吗？
│      └─ 防火墙？IP 冲突？网关？
├─ 参数层
│  ├─ 波特率/数据位/校验/停止位一致吗？
│  ├─ 站号对吗？（1~247）
│  └─ TCP 端口对吗？（Modbus 502、S7 102、OPC UA 4840）
├─ 协议层
│  ├─ 用串口助手发已知帧有回包吗？
│  ├─ 回的是异常码吗？（02=地址，0B=网关找不到从站）
│  ├─ 地址基址对吗？（40001 ↔ 0）
│  └─ 字序/量程对吗？（数值离谱但量级对 → 字序）
└─ 程序层
   ├─ 超时设太短？
   ├─ 两帧间隔太短？
   ├─ 没清接收缓冲，把残包当应答？
   └─ 多线程并发读同一个口？
```

## 3. 常见故障速查表

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 串口打不开 | 被占用/不存在/驱动 | 关掉其他调试软件；设备管理器检查；换 USB 口 |
| 串口打开报“拒绝访问” | 另一个程序占用 | 任务管理器结束占用进程 |
| 收到乱码 | 波特率/校验/数据位错 | 逐个参数对齐 |
| 完全没数据 | 线、站号、A/B 反 | 量电压、对调 A/B、换线 |
| 偶发 CRC 错 | 干扰、无终端电阻、两帧太近 | 加 120Ω、单端接地、加 10ms 延时 |
| 读回全 0 | 地址错、从站未运行 | 核对地址表、看从站灯 |
| 异常码 02 | 地址越界/基址差 1/数量超限 | 改地址、试 0/1 基址、≤125 |
| 异常码 0B | 网关找不到从站 | 检查站号、网关映射 |
| 数值离谱 | 字序错/量程没乘/有符号 | 换 ABCD/CDAB、乘 Scale、改 Int16 |
| TCP 连不上 | IP/端口/防火墙 | ping、telnet、关防火墙测试 |
| 连接几秒就断 | 心跳缺失/NAT 超时 | 加心跳、长连接参数 |
| 界面卡顿 | UI 线程阻塞/刷新太频繁 | 后台采集、降低刷新率 |
| 内存持续涨 | 事件未退订/集合无限增长 | 退订、限制长度、压测 |
| 数据不落盘 | 磁盘满/权限/文件被占用 | 检查空间、目录权限、Excel 是否开着 |
| 时间不对 | 系统时区/未同步 | 校时、NTP、统一存 UTC |
| 程序退出后进程还在 | 线程未退出/未 Dispose | 取消令牌、等待任务、释放串口 |

## 4. 工具与命令

### 4.1 网络

```powershell
ping 192.168.1.10
Test-NetConnection 192.168.1.10 -Port 502
telnet 192.168.1.10 502
ipconfig /all
arp -a
```

### 4.2 串口

- 设备管理器 → 端口（COM 和 LPT）
- 串口调试助手（本仓库项目 1）
- 虚拟串口 com0com（无硬件联调）
- USB 转 485 看指示灯（TX/RX 闪不闪）

### 4.3 抓包

```
Wireshark 过滤：
  tcp.port == 502
  ip.addr == 192.168.1.10
  modbus
```

看三件事：**有没有发出去、有没有回来、回来的字节对不对**。

### 4.4 进程与性能

- 任务管理器 → 详细信息 → 添加“句柄数、线程数、GDI 对象”
- 资源监视器 → CPU/内存/磁盘
- Process Explorer → 看线程堆栈、句柄
- `dotnet-counters`、`dotnet-dump`（进阶）

## 5. 干扰与接地（现场玄学，其实是科学）

| 问题 | 现象 | 解决 |
|---|---|---|
| 变频器干扰 | 偶发 CRC 错、掉线 | 屏蔽双绞线、远离动力线、加磁环 |
| 地环流 | 通信时好时坏 | 单端接地、加隔离模块 |
| 电源干扰 | 设备重启 | 加 UPS、隔离变压器 |
| 长线反射 | 高速率下误码 | 终端电阻、降波特率 |
| 多点接地 | 烧接口 | 统一接地排、等电位 |

**485 排查顺序：换线 → 加终端电阻 → 单端接地 → 降波特率 → 加隔离器。**

## 6. 一次完整的现场调试记录（范例）

```
项目：某包装线 6 台设备
现象：3#灌装机每 10 分钟掉线一次，重连后恢复
排查：
  1. 日志显示 ModbusTimeoutException，站号 3，功能码 03
  2. 单独测试 3# 正常，怀疑总线干扰
  3. 观察掉线时刻，正好是旁边封箱机启动
  4. Wireshark/串口助手抓到 CRC 错误帧
  5. 检查：485 线与动力线同槽，屏蔽层两端接地
处理：
  - 485 线单独走线槽，远离变频器
  - 屏蔽层改单端接地
  - 总线两端加 120Ω 终端电阻
结果：连续运行 7 天无掉线
```

> 面试讲这个案例，比背十道八股文管用。

## 7. 客户沟通与验收

### 7.1 需求确认

- 功能清单逐条确认（签字/邮件）；
- 明确“不做什么”（防止无限加需求）；
- 变更走变更单，评估工期。

### 7.2 验收资料

```
1. 操作手册（图文，给操作工看）
2. 维护手册（给设备工程师看）
3. 点位表（地址、类型、量程、单位）
4. 网络拓扑与 IP 表
5. 安装包与授权说明
6. 培训记录
7. 验收报告（功能逐项打勾）
```

### 7.3 培训要点

- 只讲操作工用得上的（启动、停机、报警确认、报表）；
- 别讲技术细节；
- 留一张“出问题打谁电话”的卡片。
