## C1. C# 基础（1~20）

| # | 问题 | 答案要点 |
|---|---|---|
| 1 | 值类型与引用类型区别 | 栈/堆、复制值/引用、装箱拆箱 |
| 2 | `int` 与 `Int32` 关系 | 同一类型，`int` 是别名 |
| 3 | `const` 与 `readonly` | 编译期常量 vs 运行期只读 |
| 4 | `string` 与 `StringBuilder` | 不可变 vs 可变，循环拼接用后者 |
| 5 | `==` 与 `Equals` | 运算符可重载，`Equals` 虚方法 |
| 6 | 装箱拆箱 | 值类型↔object，性能损耗 |
| 7 | `ref` 与 `out` | 初始化要求不同，`TryParse` 用 out |
| 8 | `params` 作用 | 可变参数数组 |
| 9 | 可空类型 `int?` | `Nullable<T>`，`HasValue`/`Value` |
| 10 | `??` 与 `?.` | 空合并、空条件访问 |
| 11 | `is` 与 `as` | 类型判断 vs 安全转换（失败 null） |
| 12 | 字符串驻留 | 相同字面量共享内存 |
| 13 | `StringBuilder` 线程安全吗 | 否，单线程用 |
| 14 | `Array` 与 `List<T>` | 定长 vs 动态扩容 |
| 15 | `Dictionary` 原理 | 哈希桶，冲突链表/红黑树 |
| 16 | `IEnumerable` 延迟执行 | `yield`，`ToList` 才执行 |
| 17 | `IDisposable` 作用 | 释放非托管资源，`using` 调用 |
| 18 | 终结器（析构） | 非确定性，不推荐手写 |
| 19 | `nameof` 作用 | 编译期取名称，重构安全 |
| 20 | `record` 与 `class` | 值相等、不可变倾向 |

## C9. 使用建议

1. 每天刷 10 题，**说出来**而不是心里默念。
2. 答不上来的，回到对应章节补 10 分钟。
3. 项目类问题（架构、难点、现场）优先准备，占面试一半时间。
4. 第 100 题要能讲 2 分钟：为什么选这个方向、你做了什么、未来想成为什么样的人。
