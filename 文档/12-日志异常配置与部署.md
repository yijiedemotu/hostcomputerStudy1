# 12 日志、异常、配置与部署

> 本章目标：把你的程序从“我电脑上能跑”变成“客户现场能装、能升级、出问题能查”。

---

## 1. 日志规范

### 1.1 分级

| 级别 | 用途 | 例子 |
|---|---|---|
| DEBUG | 开发调试 | 每帧报文、变量值 |
| INFO | 关键流程 | 启动、连接、配置加载、用户登录 |
| WARN | 可恢复异常 | 超时一次、重试、报警触发 |
| ERROR | 功能受损 | 连接失败、写库失败、未处理异常 |
| FATAL | 程序无法继续 | 配置彻底损坏、依赖缺失 |

现场默认 INFO，排障时临时开 DEBUG（配置文件可切换，别重新编译）。

### 1.2 内容模板

```
2026-10-18 09:12:33.451 [INFO] [1#锅炉PLC] 已连接 192.168.1.10:502
2026-10-18 09:13:02.108 [WARN] [1#锅炉PLC] 读取超时 站号=1 功能码=0x03 地址=0 数量=10
2026-10-18 09:13:02.109 [ERROR] [1#锅炉PLC] 采集失败
    ModbusTimeoutException: Modbus TCP 请求超时（3000ms）...
```

必须带：**时间、级别、设备/模块、上下文（站号/地址/报文）**。

### 1.3 写入策略

- 按天滚动，保留 30 天；
- 异步写（队列 + 后台线程），避免拖慢采集；
- 单文件上限（如 50 MB），超出新建；
- 不要打印密码、密钥、身份证等敏感信息。

本仓库 `Industrial.Core/Diagnostics/Log.cs` 是同步 + lock 的简化版，够用且好懂。

## 2. 异常处理三层防线

```
第一层：方法内 try/catch —— 能处理的就地处理（超时重试）
第二层：线程/任务边界 —— 记录日志，标记设备故障，继续跑
第三层：全局兜底 —— Application.ThreadException / AppDomain.UnhandledException
```

WinForms：

```csharp
Application.ThreadException += (_, e) => Log.Error("界面线程异常", e.Exception);
AppDomain.CurrentDomain.UnhandledException += (_, e) =>
    Log.Error("进程级异常", e.ExceptionObject as Exception);
```

WPF：

```csharp
DispatcherUnhandledException += (_, e) =>
{
    Log.Error("Dispatcher 异常", e.Exception);
    e.Handled = true;   // 界面不崩
};
```

> **不要**全局吞掉所有异常继续跑。记录 + 提示 + 让用户决定是否继续。

## 3. 配置管理

| 内容 | 放哪 | 说明 |
|---|---|---|
| 设备 IP/端口/站号 | JSON | 现场可改 |
| 点位表 | JSON 或数据库 | 点位多时用数据库 |
| 数据库连接串 | 加密配置 | DPAPI/环境变量 |
| 用户 | 数据库 | 密码哈希 |
| 日志级别 | JSON | 现场可调 |
| 界面主题 | JSON | 可选 |

配置校验：

```csharp
if (config.Devices.Count == 0) throw new InvalidDataException("未配置任何设备");
if (config.Devices.Any(d => d.PollIntervalMs < 50)) throw new InvalidDataException("采集周期不能小于 50ms");
```

**启动时校验并给出明确提示**，比运行到一半崩强得多。

## 4. 打包发布

### 4.1 dotnet publish

```powershell
# 框架依赖（体积小，客户机需装 .NET 8 Desktop Runtime）
dotnet publish src/ModbusMonitor -c Release -r win-x64 --self-contained false -o publish/monitor

# 自包含（体积大 ~150MB，但双击即用，推荐给现场）
dotnet publish src/ModbusMonitor -c Release -r win-x64 --self-contained true -o publish/monitor-standalone

# 单文件
dotnet publish src/ModbusMonitor -c Release -r win-x64 --self-contained true \
    -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish/single
```

| 方式 | 体积 | 优点 | 缺点 |
|---|---|---|---|
| 框架依赖 | 几 MB | 小、更新快 | 要装运行时 |
| 自包含 | 100~200 MB | 免装运行时 | 大 |
| 单文件 | 100~200 MB | 一个 exe，好分发 | 启动稍慢、杀软误报多 |

> 工控机常常没网、系统老旧，**自包含最省事**。但要注意目标机是 x64 还是 x86。

### 4.2 安装包（Inno Setup）

```ini
[Setup]
AppName=产线监控上位机
AppVersion=1.0.0
DefaultDirName={autopf}\UpperComputer
DefaultGroupName=UpperComputer
OutputDir=dist
OutputBaseFilename=UpperComputer-Setup-1.0.0
Compression=lzma2
SolidCompression=yes
ArchitecturesInstallIn64BitMode=x64

[Files]
Source: "publish\*"; DestDir: "{app}"; Flags: recursesubdirs createallsubdirs

[Icons]
Name: "{group}\产线监控上位机"; Filename: "{app}\ModbusMonitor.exe"
Name: "{autodesktop}\产线监控上位机"; Filename: "{app}\ModbusMonitor.exe"

[Run]
Filename: "{app}\ModbusMonitor.exe"; Description: "启动程序"; Flags: nowait postinstall skipifsilent

[UninstallDelete]
Type: filesandordirs; Name: "{app}\logs"
Type: filesandordirs; Name: "{app}\data"
```

要点：

- 默认装 `Program Files`，数据/日志写 `ProgramData` 或安装目录（注意权限）；
- 卸载时问用户是否保留数据；
- 安装包签名（可选，减少 SmartScreen 警告）。

### 4.3 开机自启

```csharp
// 注册表（当前用户）
using var key = Registry.CurrentUser.OpenSubKey(
    @"Software\Microsoft\Windows\CurrentVersion\Run", writable: true);
key?.SetValue("UpperComputer", $"\"{Application.ExecutablePath}\"");
```

或任务计划程序（可延迟启动、可提权）。

### 4.4 注册为 Windows 服务

适合无人值守采集（不需要界面）：

```powershell
sc.exe create UpperComputer binPath= "C:\App\Collector.exe" start= auto
sc.exe start UpperComputer
```

或用 `Microsoft.Extensions.Hosting.WindowsServices` 把控制台程序变成服务。

## 5. 升级

| 方案 | 说明 |
|---|---|
| 手动覆盖 | 小项目够用，注意先停程序 |
| ClickOnce | 微软自带，配置简单，适合内网 |
| AutoUpdater.NET | 检查 XML/JSON 版本文件，自动下载替换 |
| 自研升级器 | 主程序退出 → 升级器替换文件 → 重启 |

升级必须考虑：

- 配置文件格式兼容（新增字段要有默认值）；
- 数据库结构迁移（版本表 + 脚本）；
- 升级失败能回滚；
- 升级前自动备份数据和配置。

## 6. 现场部署清单

- [ ] 目标机系统版本、位数确认（x64/x86）
- [ ] .NET 运行时（框架依赖时）或自包含包
- [ ] 安装路径无中文、无空格（避免老组件问题）
- [ ] 数据/日志目录有写权限
- [ ] 防火墙放行端口（502/102/4840/自定）
- [ ] 杀毒软件白名单
- [ ] 屏幕分辨率、缩放比例适配
- [ ] 系统时间正确（NTP），否则历史数据时间全错
- [ ] 断电恢复后能自启动
- [ ] 串口驱动（CH340/CP2102/FT232）已装
- [ ] 备份策略与磁盘剩余空间
- [ ] 交接文档 + 培训
