# 从零手敲 VComPair：免驱动虚拟串口对工具完整实现教程

> 这不是"读源码"，是**从空项目开始，一行一行敲出一个能跑的工具**。
> 每一章都是一个可编译、可运行的里程碑；每章末尾都有「验收」，跑通了再进下一章。
> 教程里的代码与仓库里 `com0com虚拟串口工具/VComPair/` 的最终源码**逐字一致**（中间里程碑是同一份代码的渐进版本）。

---

## 0. 你会做出什么

一个 Windows 窗口程序，点一下「① 启动服务」，就在一台没有串口、没装 com0com 的电脑上造出一对互联的"虚拟串口"：

```
   VCOM1 写 ──► [ 你的程序 ] ──► VCOM2 读
   VCOM2 写 ──► [ 你的程序 ] ──► VCOM1 读
```

- 免驱动、免管理员、零 NuGet 依赖，只要 .NET 8；
- 窗口里自带两个终端，能 HEX/文本互发、自动应答、回环自测；
- 右侧监控窗口打印每一帧的方向、HEX、ASCII；
- 最后和本仓库的串口调试助手对接，完成真正的"上位机 ↔ 仪表"通讯闭环。

**你将练到**：WinForms 布局（Dock / SplitContainer）、TCP 服务端与客户端、异步任务与取消令牌、多线程与 UI 线程切换、事件驱动设计、握手协议设计、接口抽象与可替换实现、资源释放与异常处理。

## 4. 全局架构（先有地图，再敲代码）

```
┌──────────────────────────── VComPair.exe ────────────────────────────┐
│  MainForm（UI 线程）                                                  │
│    ├─ 顶部工具条：启动 / 停止 / 端口 / 回环 / 清空 / 说明              │
│    ├─ 左：TerminalPanel(VCOM1)   TerminalPanel(VCOM2)  ← SplitContainer│
│    ├─ 右：RichTextBox 监控  +  操作步骤                                │
│    └─ 底：状态栏                                                       │
│         │ 事件订阅（Log / Traffic / StatusChanged）                    │
│         ▼                                                             │
│  PairHub（后台线程，127.0.0.1:9527）                                   │
│    ├─ 握手：HELLO|端点|标签 → +OK / -ERR                              │
│    ├─ 会话表：每个端点只允许 1 个连接                                  │
│    ├─ 转发：A→B、B→A（回环模式 A→A）                                  │
│    └─ 离线缓存：对端没连时先攒着，上线补发                             │
└──────────────────────────────▲──────────────────────────────────────┘
                               │ TCP 回环（本机 socket）
      ┌────────────────────────┴────────────────────────┐
      │ VirtualClient（工具自带终端）                    │
      │ VirtualSerialPort（串口调试助手，实现 ISerialPort）│
      └─────────────────────────────────────────────────┘
```

**线程模型（最重要的一条）**：`PairHub` 和 `VirtualClient` 的回调都在**后台线程**触发，
WinForms 控件只能在 UI 线程访问，所以一律用 `BeginInvoke`（`Ui(...)` 辅助方法）切回来。
这条规则贯穿 M4、M5，忘了就会遇到"界面不更新 / 随机崩溃"。

## 6. 建议的学习方式

1. **先跑成品**（5 分钟）：`dotnet run --project com0com虚拟串口工具/VComPair`，点「① 启动服务」，随便发一帧，看看终点长什么样。
2. **按 M0→M6 敲**：每章先读"这一章要解决什么问题"，再敲代码，最后做验收。
3. **每章问自己三个问题**：数据从哪来？在哪个线程？谁负责释放资源？
4. **敲完再读** [07 排错复盘](07-调试排错与真实踩坑复盘.md)：里面 6 个坑都是本项目真实踩过的，对照理解会更深。
5. 最后用 [08 验收清单](08-验收清单与扩展任务.md) 自测，再做几个扩展任务。
